# Навыки проекта «Заря»

Публичные версии локальных навыков Codex. Состояние: 27 октября 2026 года.

| Навык | Назначение |
|---|---|
| [mango-staff-mobile-setup](skills/mango-staff-mobile-setup/SKILL.md) | Подбор мобильных номеров, подписи, входящие схемы, исходящий АОН и разрешённые тесты через Asterisk |
| [zarya-crm-semantic-layer](skills/zarya-crm-semantic-layer/SKILL.md) | Правила чтения Озера, проверки источников и интерпретации CRM-показателей |
| [zarya-unrecognized-cities](skills/zarya-unrecognized-cities/SKILL.md) | Подбор городов из справочника с проверкой региона и полноты списка |

## Установка

Скопируйте нужные папки из skills в свою локальную папку навыков Codex (~/.codex/skills). Настройте разрешённые подключения отдельно и проверьте актуальные контракты сервисов. Содержимое репозитория не является разрешением менять CRM или телефонию и не включает действующих доступов.

## Публичная версия

Внутренние адреса и пути заменены маркерами. Производственная выгрузка метаданных CRM, реальные телефоны и персональные примеры не включены. Файлы доступов, ключи, токены, журналы звонков и клиентские данные не публикуются. Локальные оригиналы навыков сохранены без изменений.

## Проверка

В mango-staff-mobile-setup/scripts находится офлайн-валидатор плана и его тесты. assets/crmcalls-test.wav — синтезированная фраза «Тестовый звонок crmcalls. Проверка входящей линии» (8 кГц, 16 бит, моно). При звонке учитывайте ранний ответ АТС и добавляйте подходящую паузу перед фразой; подробности — в references/test-call.md. Тестовые звонки выполняются только по прямому поручению.
