# Конфигурация и выполнение

Рабочие приложения, скрипты, снимки и подключения, упомянутые ниже, задаются отдельно и не входят в публичный пакет навыка.

| Наблюдение | Допустимый вывод | Дополнительная проверка |
|---|---|---|
| Пятнадцать отправочных узлов | В разобранном дереве пятнадцать действий | Какие ветви исполнены в конкретном workflow |
| Две ветви имеют одинаковое условие | Возможно перекрытие | Тип блока выбора и реальный порядок/семантика ветвей |
| Действие ссылается на результат чужого узла | Ссылка в шаблоне подтверждена | Значение переменной в исполнении и ожидаемая связь |
| Одинаковый UUId | Повтор идентификатора подтверждён | Использует ли кастомный код его как общий ключ состояния |
| Значение «00000» или повтор линии | Потенциальная заглушка/вес в списке | Фактическая обработка выбора в коде |
| Выбор линии до проверки времени | Порядок узлов подтверждён | Изменяется ли состояние выбора при каждом вызове |
| API принял сообщение | Подтверждено принятие при проверенном ответе | Доставка/прочтение по соответствующим статусам провайдера |

Пример: сконфигурированы два идентичных условия, но тип блока неизвестен. Не называй вторую ветку недостижимой, пока не проверена семантика выбора.

Пример: в журнале есть старт процесса и успешный вызов вложенного БП, но отсутствуют его шаги. Нельзя объявлять отправку или выбор конкретной линии доказанными.

Пример: просмотрщик показывает только извлечённые SMS-узлы. Отсутствие ChatApp в списке не доказывает отсутствие ChatApp в исходном процессе.
