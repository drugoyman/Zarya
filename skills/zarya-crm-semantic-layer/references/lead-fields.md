# Карта полей лидов

Производственная карта полей и заполненность намеренно не публикуются. Для нужных полей получите определения и подписи из b_user_field и b_user_field_lang через существующее разрешённое подключение только для чтения. Проверяйте ENTITY_ID, тип, MULTIPLE и физические колонки; не угадывайте FIELD_NAME по старому снимку. Идентификаторы полей сопоставляйте с актуальными бизнес-определениями отдельно.
