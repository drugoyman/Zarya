# Семантический слой CRM

Публичная версия не содержит снимка производственной схемы, значений или агрегатов компании. Получите определения полей через разрешённый источник только для чтения и проверьте выбранную базу.

- Для пользовательских полей сопоставляйте ENTITY_ID, FIELD_NAME, тип и множественность. Название не подтверждает бизнес-формулу.
- Текущее значение стадии не заменяет историю переходов. Договор в сделке и текущая стадия лида — разные источники.
- Не объявляйте назначенную встречу состоявшейся, CRM-событие — разговором, соединение — ответом человека.
- ID сотрудников, городов, перечислений и API не взаимозаменяемы. Сопоставляйте их по проверенным ключам.
- Сохраняйте границы интервала, часовой пояс, время обновления и ограничения покрытия. Пусто не равно нулю.
- Все запросы ограниченные, параметризованные, в read-only транзакции со statement timeout и rollback.
