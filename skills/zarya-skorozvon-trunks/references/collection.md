# Источники и полнота

Сервис, подключения, список проектов и аналитическая БД настраиваются отдельно. Код приложений в этот репозиторий не включён.

- В разрешённой локальной реализации telephony-it/skorozvon_control.py проверяйте текущие классы и контракты; не выдумывайте endpoint.
- Аналитические источники project_dashboard, project_source_dashboard, trunk_dashboard, refresh_status — ориентиры. Подтвердите схему, формулы, доступность и свежесть в выбранной БД.
- Определение физических транков и их алиасов сверяйте с текущим каталогом. Исторические поручения и heartbeat не являются новым разрешением.

Если доступен только проектный каталог без детализации, можно подтвердить назначения, но нельзя подтвердить реальный отдых и дозвон.

В просмотренном `skorozvon_control.py`: `SkorozvonAPI.projects()`, `project()`, `trunks()` и `Controller.listing()` получают состояние. `Controller.preview()` / `batch_preview()` **записывают операции в локальное хранилище**, поэтому не вызывай их в режиме «ничего не менять». `SkorozvonAPI.save()`, `Controller.apply()` / `batch_step()` изменяют назначения. Повторное чтение и `signature()` защищают снимок, неопределённый исход получает `uncertain`; статус и журнал проверяются через `status()`, `batch_status()`, `history()`. Перед использованием перепроверь текущую реализацию.

## Полная выгрузка отчётного API

1. Определи максимальный размер ответа и семантику `total` по существующему клиенту. Зафиксируй конец окна; не используй постоянно движущееся «сейчас» между страницами.
2. Запрашивай короткие окна. Для насыщенного окна продолжай штатную пагинацию или дроби его. Достигнутый лимит не означает, что больше строк нет.
3. Явно согласуй включённость границ. Удали только точные граничные повторы по проверенному ключу; конфликтующие версии одного ID сохрани как расхождение.
4. Сверь число уникальных ID с доступным `total`, диапазон времени и отсутствующие интервалы. Повторно прочитай итог фиксированного окна, учитывая задержку появления звонков.
5. При насыщении минимального интервала, повторе страниц, неизвестном формате или невозможности сверки не объявляй выгрузку полной.

## Примеры решений

- Рабочие проекты сняты с транка, но на нём остаются вызовы тестового проекта: резерв не отдыхает.
- A: 10 соединений / 100 попыток, B: 1 / 2. Общий процент 11 / 102 = 10,78%, а не среднее 10% и 50%.
- API вернул таймаут при переключении, повторное чтение показывает целевое назначение: проверь журнал и другие поля; повторная запись не требуется. Если назначение прочитать нельзя, результат остаётся неопределённым.
