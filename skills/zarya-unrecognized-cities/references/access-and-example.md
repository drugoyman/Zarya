# Источники и пример

Источник задания — актуальный список «Неопознанные города», источник назначений — действующий справочник городов компании. URL, реквизиты подключения и реальные выгрузки задаются локально, а не в публичном навыке.

Для Озера используйте zarya-crm-semantic-layer: ограниченные SELECT, read-only транзакция, timeout, rollback. Проверяйте фактическое свойство привязки и тип ссылки, не переносите ID между списками по предположению.

| Исходный город | Город из действующего справочника | Регион |
|---|---|---|
| Город A | Город B | Совпадает |
| Город C | Город D | Отличается: регион C → регион D |

Пример условный. Для реального запроса проверьте полный состав списка, неоднозначные названия, активность офисов и географическую близость. Ранее заполненные корректные строки не изменяйте; формат ответа определяет текущая задача пользователя.
